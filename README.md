# slova-books

Public-domain / CC BY-SA text corpus for the Slova app reader.

Generated by `fetch-corpus.js` (Project Gutenberg, Wikisource, Aozora Bunko).

- `index.json` — catalog: `id`, `language`, `title`, `author`, `genre`, `chapters`, `chars`, `file`.
- `json/<id>.json` — one book: `version`, `id`, `language`, `title`, `titleEn`, `author`,
  `genre`, `year`, `source{type,id,url,sourceTitle,license}`, `stats{chars,chapters}`,
  `warnings[]`, `chapters[{index,title,text}]`.

Each book carries its own license in `source.license`.
